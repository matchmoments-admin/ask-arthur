## 8. Traps this session actually hit

Worth reading before touching this area.

- **Retiring a feed can silently break `is_active`.** `mark_stale_urls`/`mark_stale_ips` deactivate on `last_seen_in_feed`, so a scraper producing zero new rows can still be load-bearing — its periodic touch is what keeps prior findings active. Retiring crt.sh would have dropped 1,726 AU brand-lookalike domains out of the blocklist. **Before retiring or slowing any feed**, run the sole-source query in §0 of the plan doc.
- **`gateOrNotFound()` does not enforce on a statically prerendered route** — the flag is evaluated at build time and baked into HTML. Any route calling it needs `export const dynamic = "force-dynamic"`, enforced by `apps/web/__tests__/featureGateRuntime.test.ts`.
- **`feed_sources.last_success_at` and `consecutive_failures` have NO writer** — NULL/0 on all 68 rows. Use `feed_ingestion_log` for freshness; `feed_sources` is a roster only.
- **A test can pass against a permanently broken loop** if it mocks a state the code cannot produce. `test_cooldown_expires_after_24h` asserted release by mocking a 25h-old head row, which a cron firing every 1.8h can never create. Mock what the live system actually produces.
- **`git stash pop` with no argument pops whatever is on top** — including another session's stash. This tree has 7 pre-existing stashes. Always `git stash push -- <paths>` with `-u` for untracked, and pop by explicit ref.
- **BSD `sed` has no `\S`** — redaction patterns using it silently pass the secret straight through.
