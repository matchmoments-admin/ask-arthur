# cost_telemetry is the Lane run ledger

Every clone-watch Lane records one Outcome Row per run in `cost_telemetry` — including its quiet-day path, with `units 0` and `metadata.reason` — rather than in a new `lane_runs` table. The digest's silent-zero detector, the recheck and issue cooldowns, and `/admin/costs` already read `cost_telemetry`, a $0 row costs nothing, and the two 2026-09 incidents (#1127, #1124) were both diagnosed from those rows; a second ledger would split the one signal that has proven to work across two tables.

**Consequences.** `units` and the typed `metadata` keys on a Lane's row are a contract owned by `packages/scam-engine/src/lane-outcome.ts` (`LANES` + `LaneOutcome`, `recordLaneOutcome` the only writer); `apps/web/lib/laneHealth.ts` types its predicates against the same shapes, so a key that drifts on either side is a compile error, not a silent 0. The `(feature, provider, operation)` triples must not be renamed without grepping `/admin/costs` and the cooldowns that read "this feature's latest row"; those cooldowns are extended by a quiet run, which is intended. Brake state is read from `feature_brakes`, never inferred from a row. Lanes with no per-run row (notify-_, enforcement-_, auto-triage, the digests, …) are outside the detector until they adopt `recordLaneOutcome` — listing them would be a guard that reads as protection.

## Amendment — 2026-09-23: the roster is complete by construction

The last sentence above left most Lanes outside the detector "until they adopt `recordLaneOutcome`". The 2026-09-22 audit found what that cost: 8 of 23 clone-watch functions wrote an Outcome Row, two roster keys were not real Inngest ids, and `clone-watch-enrich-attribution` produced nothing for six days (09-11..16) with no row to say whether it ran. Decisions:

- **Roster key = the Lane's Inngest function id.** A function with two independently watched sub-lanes uses `<fnId>/<sub>` (`shopfront-clone-netcraft-auto/auto`, `…/resubmit`). `apps/web/__tests__/laneRoster.test.ts` scans every `createFunction({ id })` and fails if a roster key names no function, or if a clone-watch function is neither rostered, absence-watched, nor in its `EXEMPT` map with a reason. Unwatched is a recorded decision, never drift.
- **A flag-off Lane is not absent.** `LANE_SHAPES[lane].enabled()` names the Lane's gate; the digest skips a disabled Lane instead of paging it daily. Skip paths still write nothing.
- **One failure shape.** `recordLaneError(lane, err, meta)` writes `<feature>_error`, $0, awaited — replacing hand-rolled `-error` literals.
- **One brake read.** `brakeState(feature) → engaged | clear | unknown` (`packages/scam-engine/src/cost-log.ts`). `isFeatureBraked` is the fail-open policy; `isFeatureBrakedOrUnknown` the fail-closed one, used by every Lane that spends or sends outbound. Before this, a PostgREST error (returned, not thrown) read as `clear` in one copy and `engaged` in three.
- **Awaited writes only.** Clone-watch Lanes use `logCostAsync` / `recordLaneOutcome` inside steps; the fire-and-forget `logCost` loses rows when a run is finish-cancelled (#1069).
