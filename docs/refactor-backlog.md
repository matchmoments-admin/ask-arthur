# Refactor backlog

Prioritized structural debt, executed ticket-by-ticket (one item = one
`refactor(scope):` PR unless noted). Born from the 2026-08-08 architecture
review that also wired the enforcement layer (ADR-0024). The `refactoring`
skill governs the _process_ for each item; `/improve-codebase-architecture`
re-surveys when this list runs dry.

Ordering principle: enforcement first (makes every later refactor
regression-proof), then violations whose fix flips a warn-level fitness rule
to error (the ratchet), then duplications, then giant files (highest churn,
lowest architectural leverage — deliberately last).

## Working agreement

- One hat per PR: items here are `refactor(scope):` commits with no behavior
  change; tests green before and after every step (see the `refactoring`
  skill's checklist).
- When an item clears the last violation of a warn-level rule in
  `.dependency-cruiser.cjs`, flip that rule to `error` **in the same PR** and
  note it here.
- New structural debt found mid-task gets a row here (or a GitHub issue if it
  needs discussion) — not a silent TODO.
